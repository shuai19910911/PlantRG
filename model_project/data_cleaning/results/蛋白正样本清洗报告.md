# PlantRG 蛋白正样本清洗报告

更新时间：2026-06-04

## 清洗规则

- 输入：PlantRG protein FASTA，共 787 个文件。
- 保留：仅包含蛋白语言模型兼容字符 `ACDEFGHIKLMNPQRSTVWYXBZJUO` 的序列。
- 处理：剥离序列末端 `*` 终止符。
- 排除：含 `.`、内部 `*`、空序列或其他非兼容字符的序列。
